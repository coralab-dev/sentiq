# Security docs

Esta carpeta contiene documentacion de RLS, permisos y verificaciones manuales.

## Archivos principales

- `docs/security/rls-permission-matrix.md`: matriz de permisos por actor, tabla y operacion.
- `docs/security/rls-test-queries.sql`: queries manuales para validar RLS.

## Cuando abrir esta carpeta

- Cambios de permisos.
- Cambios de RLS.
- Cambios de roles.
- Auditorias de seguridad.
- Cambios de schema que afecten acceso a datos.

No usar estos documentos para cambios visuales o componentes UI.
